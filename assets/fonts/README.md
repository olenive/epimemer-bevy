# Fonts

`Inter-Regular.ttf` is Inter 4.1 by Rasmus Andersson and the Inter Project
Authors, under the SIL Open Font License 1.1, whose text is
`Inter-LICENSE.txt` beside it. The bar and the labels are drawn in it,
because Bevy's built-in font covers ASCII only (`src/fonts.rs`).

Source: the official release, `Inter-4.1.zip` from
https://github.com/rsms/inter/releases/tag/v4.1 (SHA-256
`9883fdd4a49d4fb66bd8177ba6625ef9a64aa45899767dde3d36aa425756b11e`). The
font is the zip's `extras/ttf/Inter-Regular.ttf`, the static regular face,
and the licence is its `LICENSE.txt`, both copied unchanged.
